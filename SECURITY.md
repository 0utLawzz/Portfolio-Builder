# Security Policy

## Supported Versions

We currently support the latest major version for security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them privately by emailing the maintainers directly or utilizing GitHub's private vulnerability reporting feature (if enabled for this repository). 

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If a fix is accepted, we will coordinate the disclosure timeline with you.
